1Dein Prüfschlüssel

Nur freigegebene Prüfpersonen können bestätigen. Der private Schlüssel bleibt ausschließlich für diese Sitzung im Arbeitsspeicher.

Fingerabdruck:

2Code der Person

Scanne den Code auf dem Gerät der Person oder füge den vollständigen Text ein. Vergleiche den Fingerabdruck auf beiden Geräten. Gib niemals Namen, Adressen oder Ausweisnummern ein.

Fingerabdruck der Person: Noch kein gültiger Code

3Berechtigung bestätigen

Geprüfte Dokumente

Ein Reisepass zeigt keine Adresse. Prüfe den Wohnsitz anhand eines Personalausweises, Aufenthaltstitels oder einer Meldebescheinigung.

Jede Bedingung ausdrücklich bestätigen

Eigene Bestätigung widerrufen

Dieser Widerruf gilt für die Person mit dem oben geprüften Code. Prüfe den Fingerabdruck erneut.

Keine Dokumentdaten werden erfasst. Bei Zweifeln bitte nicht bestätigen.
